## Evidence chain

Earliest retained intake record: **2026-09-07 UTC**. This is a documentary lower bound for the preserved project history, not a certified date of first creation. Historical reports, retained private masters and internally calculated SHA256 underpin the six [milestones](HISTORY.md).

First public publication: **not yet verified**. GitHub commit and release creation timestamps will provide a public record from actual publication onward, not retroactive proof of earlier creation. No commits are backdated.

Each public release has a stable UUID, parent public release, source-content Git commit, tag, release URL, artifact hashes and licence version in `manifests/releases/`. A manifest cannot hash itself or refer to the commit containing itself without circularity: `git_commit` identifies the preceding reviewed content commit; the release tag points to a later manifest-registration commit. The hash list covers release assets and the manifest; it does not hash itself.

The complete private masters remain with the author and are never uploaded. Public versions exclude independent unregistered third-party scenes, restricted research and private metadata. The audit retains private master hashes separately to link source copies to the public extraction. Public manifests contain only public artifact hashes.

## Rights categories

- **ORIGINAL_ZHSTUDIO**: independently authored model detail, artistic arrangement, procedural material work and documentation, to the extent protectable. AI-assisted work is disclosed, not represented as guaranteed exclusive copyright.
- **REDISTRIBUTABLE_THIRD_PARTY**: approved generic CC0 surface/sky files, preserving their freedoms and source records.
- **PUBLIC_DATA_WITH_ATTRIBUTION**: OSM-derived data (ODbL) and NSW terrain (CC BY 4.0), with separate notices and database obligations.
- **REFERENCE_ONLY**: photographs, plans, maps and reports used for research; source pixels/files excluded.
- **RESTRICTED_OR_UNCLEAR**: imported assets lacking a sufficient public grant, including Tin Sheds; excluded until clarified. Licensed external scans are also omitted to avoid combining separate share-alike terms into the community-model licence.

Metadata and hashes help identify a model and its publication chain. They are not DRM, a legal registration, proof of complete originality or an assurance that infringement cannot occur. The public licence cannot override third-party or statutory rights.
