# Rights boundaries and outstanding review

This is a source/provenance audit, not a judicial finding or a formal legal opinion. It does not require a blanket university permission letter for all independently authored geometry, and does not claim that a photograph exception automatically permits distributing any editable 3D model.

- Original Blender geometry was assembled from OSM layout, references and visual estimates; no general imported university BIM is identified in the campus scene.
- J03 includes an explicit reconstruction from approved plans (sheets 4, 13–17) and exterior references. Factual dimensions, independently authored expression and protected architectural/plan expression need to be distinguished. No special architectural-design licence is claimed.
- An imported Tin Sheds official SketchUp model, an external graffiti mesh and point cloud exist only in independent private scenes and are excluded from the public package.
- Photos and PDFs used as reference are not supplied as textures or files. A reference-only label is not itself permission to reproduce protected expression; any direct tracing/conversion discovered in future is a release gate for the affected asset.
- OSM-derived data and original authored additions require a documented rights separation. ODbL share-alike database obligations cannot be cancelled by the Community License.
- The synthetic foliage atlas was AI-assisted. The project claims no exclusive copyright in purely machine-generated elements; it only licenses any protectable author contributions and does not warrant uniqueness.

Current-law sources: Australian Copyright Act 1968 (Federal Register of Legislation), especially sections 66 and 73; ODbL 1.0; each asset's source licence. The existence of an exception for images is not represented as a conclusive editable-model clearance.
